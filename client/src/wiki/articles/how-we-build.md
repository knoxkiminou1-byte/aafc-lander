The first job is figuring out what the site needs to do. Opening a code editor comes after that.

## Start with the goal

We ask who the audience is, what action visitors should take, and what information needs to be on the page. We also ask what can wait.

## Put the content in order

A page needs a readable order. We work through headings, descriptions, images, navigation, and calls to action before adding decoration.

## Build and test

We check phone and desktop layouts, links, keyboard navigation, loading states, and basic accessibility. Any live data needs an error state because outside services do go down.

## Review and handoff

The owner should know what was built, where it is hosted, and how to request a change. We document known limitations instead of pretending a launch makes every future problem disappear.
